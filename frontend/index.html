Library Catalog

Explore media titles. Exact searches use our in-memory Binary Search Tree (BST); substring queries utilize the SQL DB.

Search Engine Modes

Exact match (BST): Queries the cached in-memory tree in $O(\log n)$ time. Case-insensitive.
Standard match: Performs a database-wide substring query across titles.

Alphabetical Sorting Traversal

Retrieves all items sorted alphabetically. Leverages an **in-order traversal** of the active BST index. Bypasses database sorting overhead to run in $O(n)$ time.

Lexicographical Bounds Search

Queries titles starting between bounds (e.g., "A" to "M") by seeking the range directly within the BST nodes. Time complexity is $O(\log n + k)$.

Loan Policy Guidelines

• Physical books, digital e-books, and journals are checked out for a maximum of 14 days.
• Returned checkouts are calculated dynamically. Late returns accumulate a fine of $0.50 per day.
• Fines must be checked and paid through the administration system. Fines are lazily computed upon return.

Reservation Queues

If catalog items are currently checked out, reserve them to place yourself in a Priority FIFO Queue.

Queue Promotion Rules

When an item is returned, the reservation queue is processed in FIFO order. The first reservation is promoted to `ready`, allocating the copy. Cancel anytime if you no longer need the item.
